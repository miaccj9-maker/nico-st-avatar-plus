# ST Avatar+ · 裁剪 & 动态头像

SillyTavern 第三方扩展。把「头像裁剪器」和「动态头像」合成一个插件：**选一次文件，酒馆原生头像就换成它**，聊天里还能自由拖动、滚轮缩放，位置按存档 / 角色 / 面具分别记住，新楼层不再回弹。

当前版本 **v1.7.3**。

---

## 它解决什么

| 老问题 | 现在的做法 |
| --- | --- |
| 侧栏一套头像、聊天里另一套头像 | 选图/裁剪后**直接写入酒馆原生头像**（`POST /api/avatars/upload` / `/api/characters/edit-avatar`），只存在一个头像 |
| 每次新楼层都先显示原生头像，再跳成自己调的位置 | 恢复存档时**不再重新 clamp**；楼层插入瞬间先摆好位移，等图片解码再补齐尺寸 |
| 拖动时贴手、松手回退一点 | 同一帧内连续移动永远取最新坐标，松手前把最后一帧补上 |
| 每个面具的头像设置互相串 | 存储键用**面具磁盘唯一 ID**（不是显示名，避免同名面具冲突）+ 存档 ID 隔离 |
| 放大后变糊 | 按「渲染尺寸 × 缩放」算实际像素宽高重绘（不是 `transform: scale()` 拉伸位图）；原生头像按 2:3 原尺寸写入，不压到 768 |
| 点角色/面具头像没法选本机视频 | 角色界面头像、面具界面 Set Image 按钮都可直接选**本机图片或视频** |

## 用法

### 换头像
- **聊天里**：右键头像、或长按头像 → 打开面板。
- **角色界面**：点角色头像预览 → 打开面板（角色已有头像文件时才接管，新建角色会走酒馆原生流程）。
- **面具界面**：点 Set Image 按钮 → 打开面板（写入的是当前面具的唯一 ID）。

面板里三选一（黑白极简界面，窄屏 / 手机自适应，不溢出）：
1. **选择本机图片或视频** —— 图片进入 2:3 裁剪页，确认后写入原生头像；视频作为动态头像（首帧写原生头像）。
2. **粘贴链接** —— 图片/视频直链，图片会尝试下载后写入原生，跨域失败则退化为叠加显示。
3. **恢复原生头像** —— 撤掉扩展换上的一切，回到酒馆原图。

### 调位置 / 缩放
- **双击头像**进入编辑模式（先出现白色描边），再拖动 / 滚轮缩放 / 双指捏合。
- 位置与缩放**自动保存**，按 `存档ID::角色|面具::名字` 独立存储，切存档、切面具、重开页面都保持。
- **重置位置与缩放**：只清位置和缩放，保留当前头像。

## 安装

1. 酒馆 → 扩展 → 安装扩展，填：
```
https://github.com/miaccj9-maker/nico-st-avatar-plus
```
2. 刷新页面。加载日志可见：
```
[ST Avatar+] v1.7.2 裁剪+动态头像合并版（原生头像同步 / 位置不回弹）
```

> 与 `avatar-cropper` 功能重叠，两者同时启用会抢同一个头像入口，建议只留本插件。

## 对外接口

```js
window.STAvatar.open(isUser)        // 打开面板：false=角色，true=面具
window.STAvatar.refresh()           // 重扫聊天，重新挂载头像
window.STAvatar.personaId()         // 当前面具的唯一 ID
window.STAvatar.resetPos(isUser)    // 清掉位置与缩放
window.STAvatar.restoreNative(isUser) // 恢复酒馆原生头像
window.STAvatar.writeNative(blob, isUser) // 把一张图写成原生头像
window.STAvatar.listPositions() / listScales() / listVideos() // 查看已存数据
```

## 存储（键名保持兼容，勿改）

- `localStorage`
  - `st_avatar_positions` —— `{ "chatId::c|u::name": {x, y} }`
  - `st_avatar_scales` —— 同上结构
  - `st_avatar_video_urls` —— 动态头像地址
  - `st_avatar_last_persona_id` —— 上次解析到的面具唯一 ID（启动早期兜底）
- `IndexedDB` `ST_Avatar_Local_DB`（v2）→ store `avatar_files`，存本机图片 / 视频的本地 blob。
